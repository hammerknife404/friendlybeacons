# Friendly Beacons

A NeoForge mod for Minecraft 1.21.1 that lets beacon effects apply to mobs, not just players, with a bigger and adjustable radius and a hidden 5th pyramid tier.

## Features

- **Affects panel:** pick who gets the powers: Passive, Friendly, Hostile and Player mobs. Player is selected by default, so beacons behave exactly like vanilla until you change them.
- **Powers preview:** see what the beacon will give, and hover a power to preview the change.
- **Radius button:** shrink a beacon's reach to keep it off a mob farm next door. The default reach is larger than vanilla's.
- **Tier 5:** an 11×11 fifth layer unlocks a 76-block radius, a bonus and Glowing for the mob types you pick.
- **Server-wide effect toggles:** in game or in the config file.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.257 or newer

## Installation

Download the jar from [GitHub Releases](https://github.com/hammerknife404/friendlybeacons/releases) and put it in the `mods/` folder on both the client and the server. A client without the mod can't join a server that has it.
